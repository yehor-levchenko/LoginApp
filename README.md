To run this project, please ensure that JDK 17 is installed on your system.

The goal of this project is not to create an app that solves a real-world problem, but rather to
demonstrate a part of my hard skills and a deep understanding of Android application architecture.

I put great effort into delivering it with high quality and correctness in terms of architecture,
modern development practices, and technologies. However, due to the simplicity of the task, I
deliberately deviated from certain clean architecture principles in order to avoid making the
project needlessly complex or inappropriate for its scope. I would be happy to explain what exactly
I simplified and why. Additionally, I’d gladly share what I would add, change, or improve if this
were a production-level project.

This project is built with Kotlin, using a simplified variation of Clean Architecture, MVVM + MVI,
Coroutines, Hilt, Jetpack Compose, JUnit and Mockito. It is designed to be reliable, stable, highly 
testable, and easily extendable.
